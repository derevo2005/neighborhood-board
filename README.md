# Дошка сусідських оголошень (Neighborhood Board)

Навчальний клієнтський вебзастосунок, розроблений у межах курсу «Програмування веб-застосувань» (Практична робота №1, Варіант 18).

## Структура проєкту
- `index.html` — базова HTML5-розмітка та каркас сторінки
- `css/style.css` — таблиця стилів
- `js/app.js` — клієнтські скрипти
- `assets/img/` — зображення та статичні ресурси
